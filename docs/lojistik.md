# Lojistik

## Item borusu

Yönlüdür (huniler gibi): ok dışındaki kollardan alır, oka verir. **Sneak + sağ tık** oku döndürür, yön Jade'de görünür. 32 item/sn, güç istemez. Tıkandığı yere koyma: yerleştirirken tıkladığın bloğa dönük doğar.

## Huni

Zincir yerine boru kullan ama huniler hâlâ girdi besler (üstten/yandan) ve çıktı çeker (alttan).

## Jade & JEI

Tüm bloklar Jade desteklidir: FE, sıvı, çıkış hızı, filtre, ilerleme görünür. Tarifler JEI'de.
