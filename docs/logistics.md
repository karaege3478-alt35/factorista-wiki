# Logistics

## Item pipe

Directional (like hoppers): pulls from every side except the arrow, pushes toward it. **Sneak + right-click** rotates the arrow, visible in Jade. 32 items/s, no power needed. Placed pipes face the block you clicked.

## Hoppers

Use pipes instead of chains, but hoppers still feed inputs (top/sides) and pull outputs (bottom).

## Jade & JEI

Every block has Jade support: FE, fluids, output rate, filter, progress. Recipes are in JEI.
