# Machines

- **Electrical furnace:** 3 inputs, silicon from sand. Chargeable with redstone.
- **Crusher:** ore doubling (iron ×2, copper ×3...).
- **Blast furnace:** iron dust + coke → pig iron (steel chain).
- **Diesel furnace:** needs no FE, burns diesel/lubricant. Hoppers pull only the output.
- **Miner 666:** pick an ore in the GUI, breaks the real block in its chunk. 500 mB gasoline per op.
- **Molding press:** sneak-right-click switches mode (pellets/sheets).
- **Auto-crafter:** crafts any recipe. Grid slots toggle on/off by clicking, 1 item per slot; right-click a slot for an item filter.
- **Reactor:** uranium rods from top/sides, hopper fed.

Hopper rules are the same everywhere: feed from top/sides, output leaves from the bottom — and only the output can be pulled.
